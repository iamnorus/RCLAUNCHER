# RCLauncher 

Custom Minecraft launcher for Fabric and Forge built with Electron.

Website: [official website](https://rclauncher.base44.app)
Discord: [Join the Discord.](https://discord.gg/hhTR7aujTU)

---

## Features
*  Easy management of Fabric and Forge versions.
*  Microsoft Account Authentication support.not yet
*  Fast downloads and automated modpack handling.

---

## Installation

### For normal users
1. Go to the [Releases](https://github.com/iamnorus/RCLAUNCHER/releases/tag/RCLAUNCHER) page.
2. Download the latest installer or executable for your operating system.
3. Run it and enjoy!
